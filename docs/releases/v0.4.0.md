# LancerLogin Guest Visits plugin v0.4.0

> **Install v0.3.0 first.** If this installation runs Guest Visits 0.2.x, update to Guest Visits **v0.3.0**, let it run, and only then update to v0.4.0. Version 0.3.0 moves the FRC and FTC credentials saved in Guest Visits into **Settings > Integrations > FIRST**; v0.4.0 deletes the place they used to be kept, so skipping 0.3.0 would lose them. **Settings > Modules** refuses the update to v0.4.0 until 0.3.0 has run, and names the 0.3.0 step (migration `0004_drop_first_caches.sql`) that has to run first. Installations already on 0.3.0, and new installations, can install v0.4.0 directly.
>
> **Needs LancerLogin 2.1.0-beta.4 or later.** Update LancerLogin before Guest Visits. Older LancerLogin releases refuse this release.

This release finishes the move of team lookup to LancerLogin's shared FIRST connection. Guest Visits no longer keeps any FIRST credentials of its own: FRC and FTC usernames and tokens live only in **Settings > Integrations > FIRST**, where they have been managed since 0.3.0. Team lookup works the same as in 0.3.0.

In the rare case that 0.3.0 could not move a saved credential (LancerLogin could not read it), that credential is removed by this release. If team lookup for FRC or FTC stops working after the update, save that program's username and token again in **Settings > Integrations > FIRST**.

It adds migration 0005, which removes the old Guest Visits credential table. Backups never contained that table, so backups made with earlier releases still restore.

## Bugs fixed

None.

## Features added

None.

## Features removed

- The FRC and FTC credentials Guest Visits kept before 0.3.0, and the code that moved them into **Settings > Integrations > FIRST**. LancerLogin's own copies are not affected.
- The warning in **Settings > Guest Visits > Team lookup** about a credential that could not be moved. Any such credential is removed by this release; save it again in **Settings > Integrations > FIRST**.
- Support for LancerLogin releases older than 2.1.0-beta.4.
