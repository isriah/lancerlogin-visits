# Release notes

Every stable or beta release tag has a matching `vX.Y.Z.md` or `vX.Y.Z-beta.N.md` file in this directory. The release is published with it as the GitHub release body. Start with the heading `# <title from .github/plugin-release.json> vX.Y.Z`, then a plain-English summary, followed by **Bugs fixed**, **Features added** and **Features removed** (write `None.` for an empty section). Include update or repair instructions only when specific user action is required. Nightly builds have generated notes and no file here.

List each release below as `- [vX.Y.Z](vX.Y.Z.md) - one-line summary`.

- [v0.2.0](v0.2.0.md) - Book from a five-week calendar with team lookup by number
- [v0.1.0](v0.1.0.md) - First release: guest visit booking, manage links, staff workspace, Discord summary and the Outreach link
